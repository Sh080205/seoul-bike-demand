ทำไมเป็น regression

ทำไม MAE เป็นเมตริกหลัก

  • หน่วยเดียวกับ target อ่านตรงๆ ว่า "ทายคลาดเฉลี่ยกี่คันต่อชั่วโมง"
  • target เบ้ขวา (mean 756.8 > median 582.5) · RMSE ยกกำลังสอง ชั่วโมงพีคไม่กี่ชั่วโมงจึงครอบงำ
  • RMSE ใช้ดูว่ามี error ก้อนใหญ่ไหม · MSE มีหน่วยคัน² จึงรายงานตามโจทย์แต่อธิบายด้วย RMSE · R² บอก % ความแปรปรวนที่อธิบายได้

ขอบเขต + กฎหลัก

  • ใช้กับ ชั่วโมงที่ระบบเปิด เท่านั้น · input ทุกตัวรู้ล่วงหน้าได้ → ไม่ใช้ lag ของยอดเช่า
  • ไม่ใช่ time-series → split ตามวันแบบสุ่ม · ทำนายระดับเมือง ไม่ใช่รายสถานี
  • ทุกอย่างที่เรียนจากข้อมูลอยู่ใน Pipeline · เลือกโมเดลด้วย GroupKFold · ห้ามดู test จนเลือกเสร็จ

ทำไมห้ามสุ่มทีละแถว

ชั่วโมง 14:00 กับ 15:00 ของวันเดียวกันมีอากาศแทบเหมือนกันและยอดเช่าใกล้กัน ถ้า 14:00 อยู่ใน train และ 15:00 อยู่ใน test โมเดลแค่ "จำ" วันนั้นได้ → คะแนน test สูงเกินจริง = leakage แบบซ่อน · วิธีแก้คือให้ ทั้งวัน (24 ชม.) อยู่ฝั่งเดียวกันเสมอ โดยใช้วันที่เป็น groups

เทียบ 3 วิธี

วิธีข้อดีข้อเสีย
GroupShuffleSplit (group = วันที่) ✓ เลือกสุ่มวันจากทั้งปี → test มีครบทุกฤดูไม่ได้จำลองการทำนายอนาคต
ตัดตามเวลาสมจริงเชิงเวลาข้อมูลมี 1 ปี → test มีแค่ 1–2 ฤดู
สุ่มทีละแถว ✗ง่ายleakage

เหตุผล: โจทย์คือ "อากาศ + เวลาแบบนี้ → เช่ากี่คัน" ไม่ใช่ forecasting จึงต้องการ test ที่ครอบคลุมทุกฤดู

ทำอะไร

  • เรียงตาม (date, hour) ก่อน → ผลการสุ่มเหมือนกันทุกเครื่อง
  • GroupShuffleSplit(test_size=0.2, random_state=42) ส่ง groups=date
  • assert ไม่มีวันอยู่สองฝั่ง และรวมครบ 365 วัน
  • บันทึก รายการวัน ลง data/splits/train_dates.csv, test_dates.csv
